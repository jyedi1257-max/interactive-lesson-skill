# 활동지 분석과 수업활동·지도안 설계

**활동지를 읽고, 학습 목표를 살린 수업활동과 실행 가능한 지도안으로 개선하는 AI 스킬입니다.**

특수학급 수업을 개선하는 과정에서 정리한 설계 기준을 담았습니다. 국어·스피치·생활경제 등의 활동지에 적용할 수 있으며, 대상 학생과 수업 조건에 맞춰 조정합니다. 특정 교재나 노션 계정이 필요하지 않습니다.

## 먼저 알려줄 정보

활동지를 첨부하고 아래 내용을 아는 만큼 적어주세요. 필요한 정보가 빠지면 AI가 질문합니다. 이미 알려준 내용은 다시 묻지 않습니다.

```text
수업 시간: 총 __분 / __차시 / 쉬는 시간 포함 여부 __
대상: __학교 __학년 또는 __세 / 학급·집단 유형 __
인원: __명
읽기·이해·표현 수준과 필요한 지원: __
과목·주제 및 활동지 범위: __
선택 사항: 강조할 목표, 공간·준비물 제한, 간결형/상세형 지도안
```

시간과 대상을 임의로 정하지 않습니다. 기본정보를 기다리는 동안 활동지 분석은 먼저 진행할 수 있습니다.

## 무엇이 달라지나요?

**활동지의 과제를 실제 수업활동으로 구안합니다.** 활동지를 분석해 무엇을 가르칠지 파악하고, 이를 학생들이 어떻게 경험하고 연습할지 설계합니다. 리듬 연습, 표현 실험, 자료 편집, 선택과 협의, 모의 운영 등 학습 내용에 맞는 활동 방식을 구체화합니다.

활동 방식을 먼저 정한 뒤 개별·짝·소집단·전체 중 적절한 참여 구성을 선택합니다. 모든 문항을 짝에게 말하고 확인하는 방식으로 처리하거나, 인원만 바꾸어 다른 활동으로 포장하지 않습니다. 이미 적절한 짝 활동과 개별·반복 연습은 유지합니다.

구체적인 활동명과 진행 순서, 시간 배분, 필요한 자료와 지원을 담아 교실에서 실행할 수 있는 지도안으로 발전시킵니다.

| 원래 활동 | 개선 예시 | 학생 반응의 영향 |
|---|---|---|
| 물건값과 거스름돈 계산 | 교실 가게 운영 — 주문받고 물건·거스름돈 건네기 | 구매 선택에 따라 계산과 제공할 물건이 바뀜 |
| 순서에 따라 설명하기 | 설명 따라 완성하기 — 친구의 안내로 준비물 배치하기 | 실제 수행 중 빠진 정보를 요청하면 설명이 보완됨 |
| 그림 속 마음 표현 | 한 장면 두 속마음 — 서로 다른 해석 더빙하기 | 서로 다른 해석을 비교하고 그림 속 근거를 찾음 |

위 예시는 설명용 창작 예시입니다. 원자료에 없는 과제로 자동 교체하지 않습니다. 개별 연습·진단·반복 학습도 목표에 맞으면 유지합니다.

## 결과물

1. **활동지 분석:** 원래 과제와 목표, 기존 수업안의 누락·축소, 확인하지 못한 자료.
2. **수업활동:** 구체적인 활동명, 준비와 진행 순서, 학생 참여 방식, 시간 배분.
3. **지도안:** 시간·활동명·진행 방법·자료의 표로 작성합니다. 자료명·쪽수·링크·준비물은 자료 열에 따로 정리합니다. 상세형은 지원·목표 확인 방법을 확장합니다.
4. **차시별 완료 보고:** 전체 작업 후 각 차시의 핵심 학습내용과 중심 활동·진행 흐름을 요약 표로 보고합니다. 이월·미반영 범위도 구분합니다.

교사 발문·학생 역할·예상 반응을 별도 항목으로 쓰는 것은 요청할 때만 추가합니다.

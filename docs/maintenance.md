# 검증과 유지관리

## v0.1 준비본

- 핵심 스킬 형식 검증 완료.
- 기본정보 누락 시 질문, 시간 자동 가정 제거, 개별 연습 인정 규칙 확인.
- 상대 경로 참조 및 배포 파일의 개인 계정 정보 점검.
- Claude Code·Codex 설치 위치와 노션 OAuth 연결을 공식 문서와 대조.
- 타 사용자 계정의 실제 설치·로그인, 모든 과목의 수업 품질은 미검증.

## 사용자가 해볼 확인

| 상황 | 확인할 행동 |
|---|---|
| 활동지만 제공 | 분석 가능한 부분을 분석하고 시간·대상 등 빠진 정보 질문 |
| 조건을 모두 제공 | 같은 질문을 반복하지 않고 수업활동과 지도안 작성 |
| 45분 요청 | 단계 시간을 합산해 45분인지 확인 |
| 원자료 일부 판독 불가 | 해당 위치를 미확인으로 표시 |
| 노션 미연결 | 원자료 파일로 수업안 작성, 자동 반영했다고 주장하지 않음 |
| 활동명만 수정 요청 | 활동 내용과 시간 유지 |

## 업데이트

`skills/redesign-interactive-lessons/`가 핵심 원본입니다. 지침을 바꾸면 일반 대화용 `prompts/chatgpt-instructions.md`에도 반영하세요. 이 파일은 핵심 지침과 활동 변환 예, 선택형 노션 지침을 한 파일로 합친 배포본입니다.

각자의 설치본은 자동 업데이트되지 않습니다. 새 버전을 내려받아 차이를 확인한 뒤 스킬 폴더를 교체합니다. 개인적으로 수정한 부분은 먼저 보관하세요.

## 이용 조건

제작자가 수정·재배포·상업적 이용 범위를 정하면 별도 라이선스 파일과 소개문을 함께 갱신합니다. 현재 준비본에는 라이선스를 임의로 지정하지 않았습니다.

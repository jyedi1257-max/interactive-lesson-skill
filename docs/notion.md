# 노션 연동에 필요한 것

활동지를 첨부해 수업안을 만드는 데에는 노션이 필요하지 않습니다. 노션에 있는 자료를 읽거나 결과를 반영하려는 경우에만 연결합니다.

## 준비할 것

- 본인의 노션 계정과 대상 페이지·데이터베이스 접근 권한.
- 사용할 AI 환경의 노션 연결 또는 원격 MCP 지원.
- 로그인·권한 승인. 관리자 정책에 따라 연결이 제한될 수 있음.
- 정확한 대상 페이지 주소, 과목·차시·날짜 및 수정할 영역.
- 수업 시간·대상·인원·참여 수준과 지원.

이 스킬을 받는 것만으로 제작자의 노션 권한이 전달되지는 않습니다. 개인 페이지를 웹에 공개할 필요도 없습니다. 인증정보를 스킬이나 공개 저장소에 넣지 마세요.

## ChatGPT에서

현재 환경에서 제공되는 노션 플러그인/앱을 선택하고 본인 계정을 연결합니다. 사용 가능한 읽기·편집 기능은 실제 연결 상태에서 확인합니다. [OpenAI 안내](https://learn.chatgpt.com/training/walkthroughs/plugins-and-skills)

연결 후 먼저 요청:

> 이 노션 페이지를 읽고 제목, 원자료 위치, 수정 가능한 수업안 영역을 알려줘. 아직 수정하지 마.

페이지는 읽히지만 첨부 활동지를 못 읽는다면 활동지를 별도로 첨부합니다. 편집 기능이 없으면 붙여 넣을 수 있는 지도안으로 받습니다.

## Claude Code에서: 공식 원격 MCP

터미널에서:

```bash
claude mcp add --transport http notion https://mcp.notion.com/mcp
```

Claude Code 안에서 `/mcp`를 실행해 OAuth 로그인과 권한 승인을 완료합니다. 위 명령의 기본 범위는 현재 프로젝트의 개인 연결입니다. 스킬 설치와 이 연결 설정은 별개입니다. [Notion 공식 연결 안내](https://developers.notion.com/guides/mcp/get-started-with-mcp)

## Codex에서: 공식 원격 MCP

기존 `~/.codex/config.toml`을 유지하며 아래 항목을 추가합니다. 이미 `mcp_servers.notion` 항목이 있으면 중복 추가하지 않습니다.

```toml
[mcp_servers.notion]
url = "https://mcp.notion.com/mcp"
```

터미널에서 인증:

```bash
codex mcp login notion
```

OAuth 로그인 후 접근할 워크스페이스를 확인합니다. [Notion 공식 연결 안내](https://developers.notion.com/guides/mcp/get-started-with-mcp)

## API 키가 필요한가요?

위 원격 MCP 경로는 OAuth 로그인 방식입니다. 이 안내를 따라 연결할 때 개인 API 토큰을 스킬에 적어 넣지 않습니다. 직접 만든 REST API 연동은 별도 구현 범위이며 이 저장소에 포함되어 있지 않습니다.

## 실제 사용 순서

1. 대상 자료가 읽히는지 확인합니다.
2. 기본정보를 전달하고 활동지 분석·수업안 개선을 요청합니다.
3. 보고 후 승인을 요청했다면 구체적인 개선안을 검토합니다.
4. 승인할 때 반영할 페이지와 범위를 지정합니다.
5. 수정 후 원문·이미지·첨부·완료 상태 보존 여부와 수정 결과를 확인합니다.

```text
이 개선안을 해당 차시의 수업활동 영역에 반영해줘.
원래 활동지·이미지·첨부와 날짜·완료 상태는 유지해줘.
반영 후 다시 읽어서 시간, 활동명, 자료 연결이 맞는지 확인해줘.
```

접근 거절은 연결 계정·워크스페이스·페이지 권한을 확인합니다. 읽기 성공이 편집 성공을 보장하지 않으므로 완료 보고에서 실제 반영 범위를 확인하세요.

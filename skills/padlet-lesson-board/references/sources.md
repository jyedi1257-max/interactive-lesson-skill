# 자료를 어디서 가져오나

여기 있는 것은 **전부 선택**입니다. 하나도 없어도 `board.json`을 직접 적으면 보드는 만들어집니다.

목표는 하나입니다. 무슨 방법을 쓰든 결과는 `board.json` 한 개입니다.

```
로컬 그림 폴더 ─┐
PDF 페이지     ─┤
노션           ─┼──→  board.json  ──→  create-board.mjs
그림 생성 도구 ─┤
직접 작성      ─┘
```

---

## 1. 직접 적기

가장 빠르고, 필요한 것이 없습니다. `examples/board.json`을 복사해서 고치면 됩니다.

하루에 한두 개 만든다면 이걸로 충분합니다. 아래 방법들은 매주 여러 차시를 만들 때만 값을 합니다.

---

## 2. 노션에 차시안이 있을 때

### 가장 쉬운 방법

노션 페이지를 열고 차시안 본문을 복사해 에이전트 대화창에 붙여넣습니다. 연동 설정이 필요 없고 결과도 같습니다.

### 연동해서 읽을 때

에이전트에 노션 커넥터나 통합 토큰이 붙어 있으면 페이지를 직접 읽게 할 수 있습니다.

```
노션 수업진도표에서 2026-09-10 국어 차시를 찾아 board.json으로 만들어 줘
```

주의할 점 세 가지입니다.

1. **날짜와 제목을 정확히 지정합니다.** "최근 것"이라고 하면 엉뚱한 차시를 집어옵니다
2. **한 페이지에 여러 차시가 섞여 있으면 범위를 말합니다.** 아래쪽에 보존된 다음 차시의 활동이 오늘 수업에 섞여 들어갑니다
3. **학생 이름이 있는 칸은 빼도록 말합니다.** 카드에 개인정보가 들어가면 안 됩니다

### 노션에서 그림 주소 뽑기

```python
import re
images = re.findall(r'!\[([^\]]*)\]\((https:[^)]+)\)', markdown)
```

노션 그림 주소는 시간이 지나면 만료되는 서명 주소입니다.

- 지금 조회한 값을 바로 씁니다
- 인증 쿼리를 임의로 자르지 않습니다
- 예전에 저장한 주소를 다시 쓰기 전에 열리는지 확인합니다
- 기록에 서명 부분을 남기지 않습니다

진도표 행에 항상 그림이 있다고 가정하지 마세요. 본문에 그림이 없으면 연결된 실제 차시안 파일을 먼저 찾습니다.

## 3. PDF에서 그림 뽑기

## 4. 그림 생성 도구를 쓸 때

수업에 필요한 낱말판이나 장면 그림이 없을 때만 씁니다.

### 먼저 확인할 것

- 정확성이 중요한 자료는 만들어 낸 그림에 의존하지 않습니다. 입모양이나 조음기관 그림이 그렇습니다
- 만들어 낸 그림을 원자료 인물이나 사건의 증거처럼 쓰지 않습니다
- 학생 개인정보를 생성 도구에 넣지 않습니다

### 노트북엘엠을 쓴다면

**이 스킬은 그 도구를 필요로 하지 않습니다.** 그림은 직접 그리거나, 원자료에서 뽑거나, 다른 도구로 만들어 공개 주소만 있으면 됩니다. 아래는 이미 노트북엘엠을 쓰고 있을 때만 보세요.

#### 연결하기

`notebooklm-mcp-cli`를 설치하면 `nlm` 명령을 쓸 수 있습니다.

먼저 연결돼 있는지 확인합니다.

```bash
nlm login --check
```

안 돼 있으면 로그인 창을 띄웁니다.

```bash
nlm login
```

브라우저 창이 열리고 **사용자가 그 창에서 직접 구글 로그인을 합니다.** 에이전트는 창을 띄우는 것까지만 하고 비밀번호를 대신 입력하지 않습니다.

| 명령 | 하는 일 |
|---|---|
| `nlm login --check` | 지금 연결돼 있는지만 확인 |
| `nlm login` | 로그인 창 띄우기 |
| `nlm login --clear` | 다른 구글 계정으로 바꾸기 |
| `nlm login --wsl` | WSL에서 윈도우 크롬 띄우기 |
| `nlm login profile list` | 연결된 계정 목록 |

계정별로 프로필이 나뉘어서 여러 구글 계정을 함께 둘 수 있습니다.

#### 연결하기 전에 알아야 할 것

- 노트북엘엠은 **공개 API가 없습니다.** 이 도구는 비공식이며, 구글이 화면을 바꾸면 멈춥니다
- 로그인 세션은 시간이 지나면 만료됩니다. 그때 다시 로그인해야 합니다
- 저장되는 것은 그 구글 계정의 로그인 상태입니다. 공용 컴퓨터에서는 쓰지 마세요
- 서비스 약관에서 자동화가 허용되는 범위를 직접 확인하세요

#### 사용자에게 물을 때

연결을 대신 결정하지 않습니다. 그림을 만들어야 하는 상황이 실제로 생겼을 때만 묻습니다.

```
보조 그림을 만들려면 노트북엘엠 연결이 필요합니다. 연결할까요?
연결하지 않으면 글자 카드로 만들고, 그림은 직접 준비하시면 됩니다.
```

원하지 않는다고 하면 글자 카드로 진행합니다. 다시 권하지 않습니다.

### 만든 그림 검수

파일이 생긴 것과 내용이 맞는 것은 다릅니다.

1. 파일 형식과 크기, 열리는지 확인합니다
2. 글자를 문자 인식으로 한 번 봅니다

```python
from PIL import Image
import numpy as np
import easyocr

reader = easyocr.Reader(["ko", "en"], gpu=False)
text = reader.readtext(np.array(Image.open(image_path).convert("RGB")), detail=0)
```

윈도우에서 한글 파일 경로는 그림을 읽는 단계에서 문제가 생길 수 있어, PIL로 읽은 배열을 넘깁니다.

3. 문자 인식 결과가 이상하면 그림을 직접 봅니다. 인식이 틀렸는지 그림 글자가 틀렸는지 확인하기 전에는 정상으로 판정하지 않습니다
4. 그림이 목표 낱말과 맞는지, 순서가 맞는지, 놀이 장면이 위험한 행동으로 보이지 않는지 봅니다
5. 내용 확인이 끝나지 않았으면 완료로 보고하지 않습니다

---

## 5. 그림을 어디에 두나

카드에 넣으려면 공개된 주소가 필요합니다. 내 컴퓨터 파일을 패들렛에 직접 올리는 방법은 확인되지 않았습니다.

**학생 사진, 학생 작품, 공개 권한을 확인하지 않은 원자료를 무료 공개 저장소에 올리지 마세요.** 보드를 비공개로 두어도 그림 주소 자체는 공개된 상태로 남습니다.

공개할 수 없는 그림이라면 글자 카드로 만들고, 그림은 수업 시간에 교사 화면으로 보여 주세요.

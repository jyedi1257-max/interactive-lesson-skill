# 수업자료를 패들렛 보드로

이미 있는 수업자료를 패들렛(Padlet) 보드로 옮기는 스킬입니다.
차시안과 그림을 정해진 형식으로 적어 두면, 패들렛 API가 섹션과 카드가 갖춰진 보드를 만들고 학생 접속 링크까지 돌려줍니다.

특수학급 수업을 만들면서 정리했습니다. 학생 화면 문구 기준과 활동 설계 기준이 함께 들어 있습니다.

---

## 무엇을 해결하나

### 손으로 만들면

차시안은 이미 있습니다. 활동 순서도, 학생이 고를 말도, 자기점검 문항도 적어 두었습니다. 그런데 그걸 패들렛에 옮기려면 구역을 만들고, 카드를 하나씩 추가하고, 제목을 치고, 선택지를 옮겨 적는 일을 처음부터 다시 합니다.

차시가 바뀌면 처음부터 또 합니다. 같은 구조인데도 그렇습니다.

### 이 스킬로 하면

차시안을 설정 파일 하나로 적어 두면 보드가 만들어집니다. 구역, 카드, 투표, 색까지 들어간 채로 나오고 학생 접속 링크와 QR도 함께 나옵니다.

다음 차시는 그 파일을 복사해 내용만 바꿉니다. 구조를 다시 짜지 않습니다.

에이전트를 쓰면 설정 파일도 직접 쓰지 않아도 됩니다. 차시안을 주면 에이전트가 형식에 맞춰 만듭니다.

### 막히는 지점을 미리 치웠습니다

패들렛 개발자 API는 서드파티 문서가 거의 없습니다. 처음 쓰면 여기서 막힙니다.

- 새 보드를 만들려고 `POST /boards`를 부르면 **개인 키로는 거부됩니다.** 대신 AI Recipe 경로로 가야 합니다
- 카드를 만들었는데 **제목과 본문이 비어서 나옵니다.** 값을 한 단계 안쪽에 넣어야 합니다
- 파이썬으로 부르면 **오류도 없이 응답이 오지 않습니다.** 앞단에서 막고 있어서, 재시도해도 뚫리지 않습니다

세 가지 모두 원인이 겉으로 드러나지 않습니다. 특히 마지막은 조용히 멈춰서 무엇이 잘못됐는지도 알기 어렵습니다.

### 되돌릴 수 없다는 점이 제일 중요합니다

공개 API에는 **삭제와 수정이 없습니다.** 만들기와 읽기만 됩니다.

그래서 잘못 만든 카드는 패들렛 웹에서 손으로 지워야 합니다. 보드 하나에 카드가 열 개 넘게 잘못 들어가면 지우는 데만 한참 걸립니다.

이 스킬은 그래서 **만들기 전에 검사합니다.** 설정 파일에 빠진 제목이나 잘못된 선택지가 있으면 네트워크에 닿기 전에 멈춥니다. 만든 뒤에는 다시 읽어서 요청한 구조와 맞는지 확인하고, 다르면 무엇이 다른지 알려 줍니다.

자세한 내용은 [references/api-verified.md](references/api-verified.md)에 있습니다.

### 카드를 어떻게 쓸지도 함께 정리했습니다

API를 부를 줄 아는 것과 쓸 만한 수업 보드를 만드는 것은 다릅니다.

구역 이름을 `도입`, `정리`로 두면 학생 화면에 교사용 말이 그대로 남습니다. 활동을 전부 "댓글로 적기"로 만들면 원래 하려던 수행이 사라집니다. 이런 기준은 도구가 알려주지 않습니다.

특수학급 수업을 만들면서 정한 기준을 [references/board-design.md](references/board-design.md)에 모아 두었습니다.

## 필요한 것

| 구분 | 항목 | 설명 |
|---|---|---|
| 필수 | 패들렛 계정 | 보드를 만들 계정입니다 |
| 스크립트로 쓸 때 | 패들렛 API 키 + Node 18 이상 | 아래 `패들렛 API 키 받기` 참고. 파이썬은 요청이 막힙니다 |
| 플러그인으로 쓸 때 | 커넥터 연결만 | **키도 Node도 필요 없습니다** |
| 선택 | 차시안 | 직접 적어도 되고, **노션과 연동하면 차시안을 자동으로 불러옵니다** |
| 선택 | 그림 | 준비한 그림 주소를 넣거나, **노트북엘엠과 연동해 만들 수 있습니다.** 없으면 글자 카드만으로도 보드는 만들어집니다 |
| 선택 | js-yaml | 설정을 JSON으로 쓰면 필요 없습니다 |

설치할 것은 없습니다. Node 18부터는 `fetch`가 안에 들어 있어서 내려받은 폴더에서 바로 실행됩니다.

선택 항목은 **하나도 없어도 됩니다.** 차시안을 손으로 적고 글자 카드만 쓰면 필수 두 가지로 끝납니다. 연동은 같은 작업을 매주 여러 번 할 때 값을 합니다. 연동 방법은 [references/sources.md](references/sources.md)에 있습니다.

### 패들렛 API 키 받기

패들렛에서 **환경설정 → 개발자 → API 키 복사** 순서로 받습니다. 바로 가려면 `https://padlet.com/dashboard/settings/developers` 를 엽니다.

키는 보통 `pdltp_`로 시작합니다. 요금제에 따라 개발자 메뉴가 보이지 않을 수 있습니다. 메뉴가 없으면 패들렛 개발자 문서에서 조건을 확인하세요. 문서 색인은 `https://docs.padlet.dev/llms.txt`에 있습니다.

키를 받았으면 환경변수에 넣습니다. 키를 파일이나 명령줄에 그대로 적지 마세요.

```bash
export PADLET_API_KEY=pdltp_여기에키
```

윈도우 파워셸이면:

```powershell
$env:PADLET_API_KEY = "pdltp_여기에키"
```

## 5분 시작

1. 키가 살아 있는지 확인합니다.

```bash
node scripts/create-board.mjs --check
```

2. 예시를 그대로 한 번 만들어 봅니다.

```bash
node scripts/create-board.mjs examples/board.json
```

3. 끝나면 보드 주소, 슬라이드 주소, QR 주소가 나옵니다.

4. `examples/board.json`을 복사해서 내 차시로 고칩니다.

## 쓰는 방법은 두 가지입니다

### 1. API 키로 에이전트에서 쓰기

클로드 코드, 코덱스, 헤르메스처럼 **내 컴퓨터에서 명령을 돌릴 수 있는 에이전트**에서 씁니다. 이 폴더를 스킬 위치에 두고 차시안을 주면, 에이전트가 설정 파일을 만들고 스크립트를 돌립니다.

- API 키를 환경변수에 직접 넣습니다
- 키가 내 컴퓨터 밖으로 나가지 않습니다
- 만든 뒤 검증까지 스크립트가 합니다

에이전트 없이 명령만 직접 돌려도 됩니다.

### 2. 플러그인 연결해서 지피티·클로드로 쓰기

지피티나 클로드에 패들렛을 **커넥터(플러그인)로 연결**하면 내려받을 것도 돌릴 명령도 없이 대화만으로 보드를 만듭니다. 연결은 각 제품의 커넥터 설정에서 합니다.

**이 방식은 API 키가 필요 없습니다.** 연결할 때 계정 승인으로 붙고, 키를 적으라는 화면이 나오지 않습니다. 위의 `패들렛 API 키 받기`는 건너뛰어도 됩니다.

### 무엇이 다른가

| | 1. 에이전트 + API 키 | 2. 플러그인 |
|---|---|---|
| 준비 | 폴더 내려받기, 키 넣기 | 커넥터 연결 |
| 쓰는 법 | 차시안을 주면 알아서 | 대화로 요청 |
| 인증 | API 키 (내 환경변수) | **계정 승인. 키 필요 없음** |
| 접근 권한이 있는 곳 | 내 컴퓨터 | 연결한 서비스 |
| 그림 파일 | 주소로만 넣습니다 | 파일을 바로 올려 주기도 합니다 |
| 검증 | 스크립트가 자동으로 | 직접 확인 |
| 맞는 경우 | 매주 여러 차시, 기록으로 남기고 싶을 때 | 가끔, 빠르게 하나 만들 때 |

**접근 권한을 어디에 맡기는지가 다릅니다.** 플러그인 쪽은 연결한 서비스가 내 패들렛 계정 권한을 가지고 있습니다. 학교 계정이나 공용 계정으로 쓴다면 먼저 확인하세요.

**어느 쪽이든 카드 쓰는 기준은 도구가 알려주지 않습니다.** 아래 `설정 파일 형식`의 기준과 [references/board-design.md](references/board-design.md)를 그대로 쓰세요. 그게 이 스킬의 알맹이입니다.

## 설정 파일 형식

`board.json` 한 개가 전부입니다.

```json
{
  "보드제목": "3-2 표정으로 말해요",
  "섹션": [
    {
      "이름": "표정 풀기",
      "카드": [
        { "제목": "웃는 얼굴", "이미지": "https://example.com/smile.png" },
        { "제목": "어떤 마음일까", "투표": ["기뻐요", "신나요", "편안해요"] }
      ]
    },
    {
      "이름": "고른 이유",
      "카드": [
        { "제목": "왜 그렇게 골랐나요", "본문": "짝에게 한 문장으로 말해요" }
      ]
    }
  ]
}
```

카드에 쓸 수 있는 항목:

| 항목 | 설명 |
|---|---|
| `제목` | 필수. 카드 제목 |
| `본문` | 선택. 짧은 수행 안내 |
| `이미지` | 선택. 공개된 그림 주소 |
| `투표` | 선택. 선택지 2~4개 |
| `질문` | 선택. 투표 위에 뜨는 물음. 없으면 제목이 두 번 나옵니다 |
| `색` | 선택. red, orange, green, blue, purple |

투표 카드에는 `질문`을 함께 적으세요. 안 적으면 카드 제목이 제목 자리와 투표 질문 자리에 똑같이 두 번 나옵니다.

```json
{ "제목": "친구가 넘어졌어요", "질문": "어떤 말을 할까요", "투표": ["괜찮아?", "같이 가자", "여기 앉아"] }
```

YAML이 편하면 `examples/board.yaml`을 쓰세요. 이때만 `npm install js-yaml`이 필요합니다.

### 카드를 적는 기준

- 카드 하나에 중심 내용 하나만 둡니다
- 섹션 이름은 학생이 할 행동으로 적습니다. `도입`, `정리`, `소요시간` 같은 교사용 운영 정보는 학생 화면에 두지 않습니다
- 선택 활동은 `투표`로 만듭니다. 댓글로 적으라고 하면 활동이 줄어듭니다
- 본문에 인터넷 주소를 그대로 적지 않습니다

자세한 기준은 [references/board-design.md](references/board-design.md)에 있습니다.

## 클로드 코드 등 에이전트에서 쓰기

이 폴더에는 사람이 읽는 `README.md`와 에이전트가 읽는 `SKILL.md`가 따로 있습니다.

### 클로드 코드

폴더를 스킬 위치에 두면 됩니다.

```bash
# 나만 쓰기
cp -r padlet-lesson-board ~/.claude/skills/

# 이 프로젝트에서만 쓰기
cp -r padlet-lesson-board .claude/skills/
```

새 세션을 열고 이렇게 부릅니다.

```
오늘 3교시 표정 수업 차시안으로 패들렛 보드 만들어 줘
```

에이전트가 `SKILL.md`를 읽고 차시안에서 `board.json`을 만든 뒤 스크립트를 돌립니다.
키는 환경변수에 있어야 합니다. 대화창에 키를 붙여 넣지 마세요.

### 커서, 클라인 등 다른 코딩 에이전트

`SKILL.md`를 규칙 파일로 붙이거나, 대화 시작에 한 번 읽히면 됩니다.

```
SKILL.md를 읽고 그 절차대로 진행해 줘
```

### 헤르메스

`skills` 폴더에 그대로 두면 이름으로 불러옵니다.

### 클로드에 패들렛을 커넥터로 붙였다면

스크립트 없이 대화만으로 보드를 만들 수 있습니다. 이때도 `SKILL.md`는 함께 두세요. 커넥터는 API를 부르는 방법만 알고, 카드를 어떻게 써야 하는지는 모릅니다.

```
SKILL.md 기준으로 오늘 차시 보드를 만들고, 만든 뒤 다시 읽어서 확인해 줘
```

## 지피티에서 쓰기

두 가지 방법이 있습니다.

### 방법 1. 플러그인을 붙여서 (설치 없음)

지피티에 패들렛을 커넥터로 연결하면 대화만으로 보드가 만들어집니다. 내려받을 것도 돌릴 명령도 없습니다.

**API 키가 필요 없습니다.** 계정 승인으로 붙고 키를 적으라는 화면이 나오지 않습니다. 다만 연결한 뒤에는 지피티가 내 패들렛 계정 권한을 가지고 있으므로, 학교 계정이나 공용 계정이면 먼저 확인하세요.

연결한 뒤에는 이렇게 요청합니다.

```
아래 차시안으로 패들렛 보드를 만들어 줘.

기준:
- 카드 하나에 중심 내용 하나
- 섹션 이름은 학생이 할 행동으로
- 선택 활동은 투표로, 댓글로 적으라고 하지 않기
- 교사용 단계명과 시간은 넣지 않기

만든 뒤 섹션 수, 카드 수, 링크를 다시 읽어서 알려 줘.

차시안:
(여기에 차시안을 붙여넣기)
```

### 방법 2. 설정 파일만 받아서 직접 돌리기

플러그인을 붙이지 않았다면 역할을 나눕니다.

**지피티가 하는 일**: 차시안을 읽고 `board.json`을 만들어 줍니다
**내가 하는 일**: 그 파일을 저장하고 명령 한 줄을 돌립니다

키가 내 컴퓨터 밖으로 나가지 않는다는 것이 장점입니다.

대화창에 이렇게 넣습니다.

```
아래 형식으로 board.json을 만들어 줘. 설명은 빼고 JSON만 출력해 줘.

형식:
{
  "보드제목": "...",
  "섹션": [
    { "이름": "...", "카드": [ { "제목": "...", "본문": "...", "투표": ["...","..."] } ] }
  ]
}

기준:
- 카드 하나에 중심 내용 하나
- 섹션 이름은 학생이 할 행동으로
- 선택 활동은 투표로, 댓글로 적으라고 하지 않기
- 교사용 단계명과 시간은 넣지 않기

차시안:
(여기에 차시안을 붙여넣기)
```

나온 JSON을 `board.json`으로 저장하고 돌립니다.

```bash
node scripts/create-board.mjs board.json
```

### 방법 3. 맞춤형 지피티로 만들기

같은 형식을 계속 쓸 거면 지침에 `SKILL.md`의 "카드 만들기 기준" 부분과 위 형식을 넣어 두세요. 그다음부터는 차시안만 붙여넣으면 됩니다.

### 주의

- **대화창에 API 키를 붙여넣지 마세요.** 대화 기록에 키가 남습니다. 커넥터는 키를 묻지 않으니 넣을 일도 없습니다
- 방법 2와 3에서도 지피티에는 키가 필요 없습니다. 지피티는 설정 파일만 만들고, 키는 내 컴퓨터에만 있습니다
- **학생 이름과 개인정보를 넣지 마세요.** 카드 내용은 활동과 자료로만 적습니다

## 노션과 연동하려면 필요한 것

노션은 선택입니다. 안 써도 스킬은 그대로 돕니다. 차시안을 노션에 쌓아 두고 있을 때만 읽으세요.

### 필요한 것

| 항목 | 설명 |
|---|---|
| 노션 접근 수단 | 커넥터, 통합 토큰, 또는 그냥 복사해 붙여넣기 |
| 차시안이 있는 페이지 | 활동 순서와 자료가 적힌 페이지 |

### 가장 쉬운 방법

노션 페이지를 열어서 **차시안 본문을 복사해 대화창에 붙여넣습니다.** 연동 설정이 필요 없고, 결과도 같습니다. 하루에 한두 번 만든다면 이걸로 충분합니다.

### 연동해서 읽을 때

에이전트에 노션 커넥터가 붙어 있으면 페이지를 직접 읽게 할 수 있습니다.

```
노션 수업진도표에서 오늘 날짜 차시를 찾아 board.json으로 만들어 줘
```

이때 주의할 점 세 가지입니다.

1. **날짜와 제목을 정확히 지정하세요.** "최근 것"이라고 하면 엉뚱한 차시를 집어옵니다
2. **한 페이지에 여러 차시가 섞여 있으면 범위를 말하세요.** 아래쪽에 붙어 있는 다음 차시 내용이 오늘 수업에 섞여 들어갑니다
3. **학생 이름이 있는 칸은 빼세요.** 보드 카드에 개인정보가 들어가면 안 됩니다

### 노션에서 그림 가져오기

노션 그림 주소는 시간이 지나면 만료되는 서명 주소입니다. 지금 조회한 값을 바로 쓰고, 예전에 저장해 둔 주소를 다시 쓰기 전에 열리는지 확인하세요. 기록에는 서명 부분을 남기지 마세요.

자세한 것은 [references/sources.md](references/sources.md)에 있습니다.

## 그림 넣기

### 이 스크립트로는 주소만 넣을 수 있습니다

**공개 API의 첨부는 주소만 받습니다.** 내 컴퓨터의 그림 파일을 올리는 경로가 문서에 없습니다.

```json
{ "제목": "웃는 얼굴", "이미지": "https://example.com/smile.png" }
```

`./img/smile.png` 같은 파일 경로를 넣으면 스크립트가 만들기 전에 걸러 냅니다.

**플러그인으로 쓸 때는 다릅니다.** 커넥터나 MCP로 연결해 쓰면 그림 파일을 그대로 올려 주기도 합니다. 그 경로는 공개 API가 아니라 각 도구가 따로 마련한 것이라, 도구마다 되는 범위가 다릅니다. 파일을 그대로 쓰고 싶고 플러그인을 붙일 수 있다면 그쪽이 더 편합니다.

### 구글 드라이브 그림 넣기

드라이브에 올린 그림은 **주소 형태를 바꿔야** 카드에 그림으로 뜹니다. 네 가지를 실제로 넣어 확인한 결과입니다.

| 주소 형태 | 카드에서 |
|---|---|
| `drive.google.com/file/d/<파일ID>/view` (공유에서 복사되는 그것) | **작은 링크 미리보기**로 뜹니다. 그림이 카드를 채우지 않고 주소 이름표가 붙습니다 |
| `drive.google.com/uc?export=view&id=<파일ID>` | **안 뜹니다.** 회색 빈 그림이 됩니다 |
| `drive.google.com/thumbnail?id=<파일ID>&sz=w1000` | **안 뜹니다.** 회색 빈 그림이 됩니다 |
| `lh3.googleusercontent.com/d/<파일ID>` | **뜹니다.** 그림이 카드를 채웁니다 |

수업 보드에 그림을 보여 주려는 것이면 **맨 아래 형태를 쓰세요.**

공유 링크에서 파일 아이디만 꺼내 바꿔 붙이면 됩니다.

```
공유 링크  https://drive.google.com/file/d/1AbCdEfGhIjK/view?usp=drivesdk
                                      └──── 이 부분이 파일 아이디 ────┘
넣을 주소  https://lh3.googleusercontent.com/d/1AbCdEfGhIjK
```

파일은 **링크가 있는 사람은 볼 수 있음**으로 공유돼 있어야 합니다. 비공개면 회색 빈 그림이 됩니다.

### 그 밖의 방법

| 방법 | 확인할 점 |
|---|---|
| **노션** 페이지에 올린 그림 | 주소가 만료되는 서명 주소입니다. 지금 조회한 값을 바로 쓰고, 예전 주소는 다시 열리는지 확인하세요 |
| **노트북엘엠**으로 만든 그림 | 만든 파일도 결국 어딘가 올려서 주소가 있어야 합니다 |
| 그 밖의 저장소 | 로그인 없이 열리는 직접 주소여야 합니다 |

어떤 방법이든 **넣고 끝내지 말고 보드를 열어 그림이 실제로 뜨는지 보세요.** 주소를 넣는 데 성공한 것과 화면에 보이는 것은 다릅니다. 안 뜨면 회색 빈 그림으로 조용히 남습니다.

### 파일을 그대로 쓰고 싶다면

보드를 먼저 만들고, **패들렛 웹에서 카드에 그림을 직접 붙이는 방법**이 있습니다. 스크립트로 글자 카드까지 만들어 두고 그림만 손으로 얹는 방식입니다. 그림 몇 장이면 이쪽이 빠릅니다.

### 학생 자료는 올리기 전에

**학생 사진, 학생 작품, 공개 권한을 확인하지 않은 원자료를 공개 저장소에 올리지 마세요.** 보드를 비공개로 두어도 바깥에 올린 그림 주소는 공개된 상태로 남습니다.

공개할 수 없는 그림이라면 글자 카드로 만들고, 그림은 수업 시간에 교사 화면으로 보여 주세요.

## 안 될 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 401 | 키가 틀렸거나 만료 | 키 다시 확인 |
| `You must use a zapier integration` | `POST /boards`를 씀 | `POST /ai-recipe-boards`를 쓴다 |
| 카드가 비어서 생성됨 | `attributes.subject`에 넣음 | `attributes.content.subject`에 넣는다 |
| 파이썬에서 응답이 없음 | 클라우드플레어가 막음 | Node의 `fetch`를 쓴다 |
| 만든 보드 내용이 요청과 다름 | AI Recipe는 지시문대로 안 나옴 | 다시 조회해서 카드를 보정한다 |
| 투표인 줄 알았는데 댓글 | `attachment.poll`을 안 씀 | 투표 형식으로 넣는다 |

## 확인 시점과 범위

- 패들렛 API 동작은 **2026년 9월 기준**이며, 실제로 보드를 만들어 확인했습니다
- 패들렛 API는 아직 바뀌는 중입니다. 오래된 문서로 보이면 `https://docs.padlet.dev/llms.txt`에서 먼저 확인하세요
- **공개 API에는 삭제와 수정이 없습니다.** 만들기와 읽기만 됩니다. 잘못 만든 카드는 패들렛 웹에서 손으로 지워야 합니다
- **공개 API로는 그림 파일을 올릴 수 없습니다.** 첨부는 주소만 받습니다. 플러그인으로 쓸 때는 파일을 올려 주기도 하며, 그 범위는 도구마다 다릅니다
- 커넥터 연결은 계정 승인으로 붙고 API 키를 요구하지 않는 것을 확인했습니다
- 구글 드라이브 주소는 네 가지 형태를 실제로 넣어 확인했습니다. `lh3.googleusercontent.com/d/<파일ID>`만 그림으로 뜹니다
- 어느 요금제부터 개발자 메뉴가 보이는지는 확인하지 못했습니다

## 개인정보

- API 키는 환경변수에만 둡니다. 기록, 대화, 명령줄에 남기지 않습니다
- 학생 이름과 개인정보는 카드에 넣지 않습니다
- 인쇄물과 공유 링크가 어디까지 가는지 확인하고 나눠 주세요

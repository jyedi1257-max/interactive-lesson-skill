# 활동지 분석과 수업활동·지도안 설계

## 목적과 조정 가능한 기본값

활동지의 학습 목표와 과제를 학생들이 실제로 경험하고 연습할 수 있는 수업활동으로 구안한다. 말하고 듣기뿐 아니라 관찰·조작·제작·표현·실험·선택·수행 등 목표에 필요한 학습 행동을 설계한다. 활동지 문항을 순서대로 읽거나 모든 활동에 짝 확인을 붙이는 데 머무르지 않는다.

활동지 분석(부분별 수업 방식 적합성 판단 포함) → 수업활동 재구성 → 지도안 작성 순서로 수행한다. 새 수업안을 만들 때와 기존안을 개선할 때 모두 적용한다. 특정 앱이나 API 없이 읽을 수 있는 원자료만으로 핵심 작업을 수행한다.

다음은 조정 가능한 기본값이다. 현재 요청과 이어지는 대화에서 확인한 조건을 우선한다.
- 수업 시간은 사용자가 지정한 총시간과 차시 구성을 따른다. 시간이 없으면 먼저 확인한다. 100분이나 특정 차시 구성을 자동 적용하지 않는다.
- 핵심 활동·진행 방법·시간 배분·활동지 연결을 간결하게 제시한다. 교사 발문·학생 역할·예상 반응의 별도 상세 항목은 요청할 때만 추가한다. 누가 어떤 정보를 주고받는지는 진행 방법에 필요한 만큼 설명한다.
- 제목만 봐도 무엇을 하는지 드러나는 활동명을 쓴다.
- 기존 활동의 학습 목적을 유지하고 준비물은 원자료와 간단한 카드·기록표 중심으로 만든다.
- 보고 후 승인을 요청한 경우에는 먼저 개선안을 제시하고 실제 편집은 승인 후 한다. 이미 승인했거나 같은 방식으로 직접 반영하라는 요청이면 다시 승인을 요구하지 않는다.

## 1. 범위와 현재 자료 확인

대상 일정표·과목·요일·시작 차시·제외 수업·완료 여부를 확인한다. 이전 대화의 특정 날짜·제외 과목을 새 작업에 자동 적용하지 말고 현재 요청과 이어지는 범위를 따른다. 제목만으로 추정하거나 미요청 과목까지 확장하지 않는다.

입력은 PDF·이미지·문서·붙여 넣은 텍스트 등 현재 환경에서 실제로 읽을 수 있는 자료를 사용한다. 사용할 수 없는 OCR·파일 도구나 앱 연결을 있다고 가정하지 않는다. 읽지 못한 부분은 위치와 함께 미확인으로 표시하고, 분석 가능한 부분부터 진행한다. 핵심 과제 자체를 확인할 수 없을 때만 해당 쪽의 선명한 이미지나 텍스트를 요청한다. 원자료가 없으면 자료를 요청하며 실제 분석 결과를 꾸며내지 않는다.

### 수업안 작성 전 기본정보 받기

현재 요청과 이어지는 대화에서 이미 확인된 정보는 활용하고 다시 묻지 않는다. 다음 핵심 정보가 빠졌으면 누락 항목만 한 번에 짧게 질문한다. 답변 전에도 읽을 수 있는 활동지의 내용 분석은 진행할 수 있지만, 수업 시간·대상을 임의로 정해 완성 지도안을 작성하지 않는다.

| 확인 항목 | 필요한 내용 |
|---|---|
| 수업 시간 | 총 몇 분인지, 몇 차시인지. 여러 차시이면 차시별 시간과 휴식 포함 여부 |
| 대상 | 학교급·학년 또는 연령대, 학급·집단 유형 |
| 인원 | 참여 학생 수 |
| 참여 수준과 지원 | 읽기·이해·말하기 등 활동 관련 수준, 그림카드·AAC·계산 지원 등 필요한 지원 |
| 과목·주제와 자료 범위 | 어떤 과목·주제인지, 사용할 활동지와 쪽·문항 범위 |

활동지나 현재 요청에서 명확한 과목·범위는 재질문하지 않는다. 장애명만으로 수행 수준을 추정하지 않고 학생 이름이나 진단명 제출을 요구하지 않는다. 교사가 수준을 잘 모르면 쉬운 진입 활동과 지원 선택지를 제공하고 미확인임을 밝힌다. 사용자가 명시적으로 조건을 맡기거나 예시안을 요청한 경우에만 가정한 조건을 적어 작성한다.

추가로 목표·강조점, 공간·준비물·기기 제한, 간결형/상세형 출력 희망을 선택적으로 받을 수 있다. 제약 정보가 없으면 특별한 장비가 필요한 활동을 기본으로 넣지 않는다. 단순 활동지 분석이나 활동명만 수정하는 요청에는 불필요한 수업 기본정보를 요구하지 않는다. 기존 수업안이 없으면 누락 비교 대신 새 활동을 설계한다.

질문 예: “수업안을 맞추려면 아래 빠진 정보만 알려주세요. ① 총시간·차시 구성 ② 대상 학년·집단과 인원 ③ 읽기·표현 수준 및 필요한 지원. 과목과 자료 범위는 첨부 활동지에서 확인했습니다.” 실제로 자료를 확인한 경우에만 마지막 문장을 쓴다.

노션을 읽거나 수정하라는 요청이 있을 때만 [references/notion-workflow.md](references/notion-workflow.md)를 읽는다. 사용 방법·출력 선택·배포 구성을 설명할 때는 [references/usage-guide.md](references/usage-guide.md)를 참고한다.

이미 존재하는 100분 수업을 다시 발견하면 시간을 새로 늘렸다고 보고하지 않는다. 실제 개선이 시간인지, 활동 내용인지, 활동명인지 구분한다. 활동명만 요청하면 이름만 바꾼다.

## 2. 원자료 과제와 수업안 대조

쪽·슬라이드·문항별로 원자료의 질문, 보기, 어휘, 금액, 작성 칸과 학습 목표를 파악한다. 전사된 활동 설명과 실제 원본 확인을 구분한다. 그림 묘사나 이미지 생성 프롬프트는 원본 이미지가 아니다. 깨진 OCR·누락 격자·확인 불가 이미지를 추측해 원문처럼 채우지 않는다.

다음 연결을 내부적으로 확인하고 반영 정도를 물으면 표로 제시한다.

| 원자료 위치 | 원래 과제 | 기존안의 누락·축소 | 개선 활동 | 수행 범위 |
|---|---|---|---|---|
| 쪽/문항 | 학습할 내용과 행동 | 실제 대조한 결과 | 참여 방법 | 공통·개별 선택·다음 차시·보충·미확인 |

- 원래 질문·보기·핵심 사례·금액·작성 항목을 유지한다. 근거 없이 창작 예시로 대체하지 않는다.
- 원문이 상상·더빙·브랜딩을 요구하면 그 창작 활동을 살린다. 모든 과제를 사실 찾기로 바꾸지 않는다.
- 활동지 충실도를 전 문항 소화로 오해하지 않는다. 핵심 과제를 깊게 배정하고 선택·이월 문항을 명시한다. 모둠별 분담 완료를 전원 완료로 표시하지 않는다.
- 자료가 없는 차시는 기존 확인 자료를 연결하거나 교사 보충안으로 작성하고 출처의 한계를 표시한다. 별도 원자료의 반영률을 꾸며내지 않는다.
- 반영률 수치를 요구하면 분모와 기준을 밝힌다. 과제 유형 반영과 개인별 문항 완료율을 구분한다.
- 오래된 가격·금리·임금·제도는 교재 사례로 구분한다. 실제 적용 규칙을 새로 설명할 필요가 있으면 공식 자료로 검증한다. 학습용 사례를 현재 시세나 법적 조언으로 제시하지 않는다.

## 3. 활동 구안 후 참여 구성 선택

### 활동지 부분별 수업 방식 적합성 분석

활동을 구안하기 전에 쪽·문항 또는 같은 목표의 문항 묶음별로 **활동지에 어떤 내용이 있는가 → 무엇을 하도록 요구하는가 → 그 과제에 어떤 수업 방식이 적합한가**를 분석한다. 판단 근거는 활동지의 설명·예제·문항·보기·작성 칸·활동 지시이다.

**분석 대상은 활동지이지 학생의 현재 능력이 아니다.** 활동지에 개념 설명이나 계산 문제가 있다는 이유로 학생이 처음 배우거나 이미 배웠다고 판단하지 않는다. 선행학습·숙달 여부·수행 가능성을 추정하거나, 이를 분류하기 위한 진단·추가 질문을 자동으로 넣지 않는다. 활동지 기반 분석에는 학생 수준 정보가 필요하지 않다. 수업 시간·대상·인원 등 지도안 작성에 필요한 기본정보 확인은 별도로 유지한다. 교사가 명시한 지원·운영 조건은 실제 진행에 반영하되 활동지에서 확인한 사실과 구분한다.

- 학습 요구를 개념 이해, 절차 확인, 문제풀이·반복 연습, 적용·판단, 개인 선택·표현, 공동 해결 등으로 구분한다. 활동지가 요구하는 행동과 결과물에 근거해 선택 이유를 설명한다.
- 교수학습 방식(강의·직접교수, 문제풀이, 모의 상황 실습, 문제해결 등)과 참여 구성(개인·짝·팀·전체)을 별도로 선택한다. 서로 배타적인 여섯 유형으로 분류하지 않는다.
- 모든 유형을 한 수업에 넣지 않는다. 사용자가 명시한 강의식·개별 등 조건을 우선하며, 변경이 필요하면 이유와 대안을 보고하고 임의로 바꾸지 않는다.

| 검토할 방식·구성 | 활동지에서 확인할 근거 | 설계 시 지킬 점 |
|---|---|---|
| 강의식·직접교수 | 개념·용어·규칙 설명, 원리 해설, 절차·예제 제시 | 해당 내용을 설명·시범으로 전달하고 원문 확인 과제로 연결한다. ‘학생이 모르기 때문’이 아니라 설명할 내용의 성격을 이유로 든다. |
| 개인활동 | 개인의 선택·생각·계획을 적거나 각자 계산·기록·표현하는 과제 | 개인별 응답과 수행 시간을 확보한다. 개인 판단을 불필요한 합의로 바꾸지 않는다. |
| 팀활동 | 서로의 의견·정보를 비교하거나 공동 결정·제작·해결을 요구하는 과제 | 무엇을 함께해야 하는지 구체화한다. 원문에 없는 협력 구조를 제안하면 수업용 보충 설계임을 밝힌다. |
| 모의 상황 실습 | 거래·서비스 이용·절차 실행·상황 대응 등 실제 맥락의 수행 과제 | 원문의 절차·조건·표현을 실제처럼 실행하고 결과를 확인하도록 구안한다. 계산 문항만 있다는 이유로 모의 가게로 바꾸지 않는다. 특별한 앱은 필수가 아니다. |
| 문제해결형 | 조건·원인·대안을 비교하고 근거 있는 해결책을 선택·수정하는 과제 | 문제와 제약, 판단 기준, 해결 결과를 확인할 방법을 구체화한다. 학생의 기초지식 부족을 가정하지 않는다. |
| 문제풀이·반복 연습 | 계산·빈칸·분류·연결·정답 확인 등 원문 문항을 풀고 확인하는 과제 | 실제 문항을 풀고 오류를 수정할 시간을 확보한다. 원문 예제가 있으면 풀이 설명에 활용한다. 문제해결형으로 이름만 바꾸지 않는다. |

한 활동지에 여러 성격의 부분이 있으면 그 연결에 따라 수업 흐름을 설계한다. 예를 들어 ‘거스름돈 정의·예제 → 계산 문항 → 구매 상황에서 선택·계산’으로 구성되어 있다면 설명·예제 풀이 → 개별 문제풀이 → 모의 구매 활동을 검토할 수 있다. 이는 자료의 구성에 근거한 제안이지 학생의 숙달 단계 판정이 아니다. 없는 적용 과제를 자동으로 추가하거나 모든 활동지에 이 순서를 강제하지 않는다.

수업활동 개선안에는 지도안 앞에 다음 **수업 방식 선택 근거 표**를 간결하게 제시한다. 같은 근거의 문항은 묶되 방식이 달라지는 부분을 숨기지 않는다. 전체 후보 비교나 긴 이론 설명은 매번 출력하지 않는다. 활동명·표 형식만 수정하는 요청에는 분석을 새로 확대하지 않는다.

| 원래 과제·요구 행동 | 추천 방식·참여 구성 | 활동지에 근거한 선택 이유·진행 연결 | 자료 |
|---|---|---|---|
| 실제 확인한 내용과 지시 | 주된 방식과 필요한 보조 방식 / 개인·짝·팀·전체 | 설명·문제풀이·선택·협력 등 과제 성격에 따른 이유 | 원자료명·쪽/문항, 보충 자료·확인 상태 |

활동지를 읽지 못했으면 실제 문항별 분석처럼 작성하지 않는다. 확인된 원문과 교사 보충안을 구분하며, 학생이 이미 습득했거나 아직 할 수 없다는 판단을 분석 결과에 넣지 않는다.

### 활동지 과제를 교실에서 실행할 경험으로 바꾸기

원래 과제의 학습 목표 → 수업 방식 적합성 판단 → 학생이 해볼 학습 행동 → 활동 방식과 실행 흐름 → 적절한 참여 구성 순서로 설계한다. 먼저 짝을 정한 뒤 모든 문항에 대화를 붙이지 않는다. 원문 문장을 풀어 나열하거나 이름만 게임·미션·역할극으로 바꾼 것은 활동 구안이 아니다.

중심 활동마다 내부적으로 서로 다른 방식의 후보를 둘 이상 검토한 뒤 목표·학생 지원·준비 부담에 맞는 것을 고른다. 후보 목록을 사용자에게 매번 출력할 필요는 없다. 선택한 활동에는 원자료의 어떤 내용을 사용하는지, 학생이 무엇을 조작·표현·판단·수행하는지, 어떤 순서로 진행하고 무엇을 남기거나 확인하는지가 드러나야 한다. 상호작용 활동이라면 상대의 반응이 진행에 미치는 영향도 구체화한다.

### 짝 활동에 편중되지 않기

- 활동 방식(리듬 연습·표현 실험·자료 편집·제작·모의 운영·탐색 등)과 참여 구성(개별·짝·소집단·전체)을 구분한다. 짝을 모둠으로 바꾸는 것만으로 활동이 다양해졌다고 판단하지 않는다.
- 짝 활동은 일대일 설명·듣기·연습에 적합할 때 선택한다. 전체가 같은 자료를 비교하는 표현 실험, 개인이 직접 조작하는 연습, 여러 기능을 연결하는 모의 운영 등 다른 구성도 목표에 맞게 사용한다.
- 한 수업과 여러 차시를 모두 살펴 학습 행동과 진행 구조가 반복되는지 확인한다. '개별 작성 → 짝에게 말하기 → 서로 확인'이 여러 중심 활동에 반복되면 목적에 맞는 대안으로 다시 구안한다. 제목만 바꾸거나 다른 인원으로 같은 절차를 반복하지 않는다.
- 다양성에 숫자 할당을 두지 않는다. 한 수업에 개별·짝·모둠·전체를 모두 넣거나 활동마다 자리를 바꾸도록 강제하지 않는다. 적합한 짝 활동은 유지한다. 하나의 좋은 중심 활동을 충분히 운영하는 것도 가능하다.
- 전체 활동에서는 일부 학생만 시연하고 나머지는 기다리지 않게 관찰할 기준·개별 선택·동시 수행·교대 등 목표에 맞는 참여를 마련한다. 소집단에서는 능숙한 한 명이 학습 행동을 독점하지 않도록 한다. 복잡한 순환·역할 분담으로 지원 부담을 늘리지 않는다.

### 상호작용이 필요한 활동의 점검

상호작용을 목적으로 설계하는 중심 활동에는 다음 세 가지를 확인한다. 개별 연습·진단·반복 학습까지 이 조건에 맞추지 않는다.
1. **서로 다른 출발점:** 가진 정보, 궁금한 것, 원하는 것, 판단 기준, 조건 또는 해석이 다르다.
2. **듣고 해야 할 일:** 주문한 물건 준비, 소개판 구성, 제목 선정, 조건 협의, 지출 배분, 설명을 따라 해보기 등 구체적인 일이 있다.
3. **반응의 결과:** 친구의 선택·질문·행동이 내 다음 설명, 거래, 조건, 계획, 표현에 영향을 준다.

상호작용 활동에 한정한 검토 질문: 상대의 선택·반응을 빼도 같은 답을 쓰고 끝나는가? 그렇다면 상호작용을 다시 설계한다. 단, 개별 진단이나 원문 연습까지 억지로 협력 과제로 만들지 않는다.

- 정보 나누기, 요청과 수행, 공동 선택, 관점 비교, 표현 실험, 협의, 거래, 체험 등을 학습 목표에 맞게 선택한다. 구체적 변환은 [references/activity-patterns.md](references/activity-patterns.md)를 필요할 때 참고한다.
- 정보차는 기억력 시험이 아니다. 자료를 보며 말하고 필요하면 공개해서 확인한다. 불필요한 비밀 규칙이나 복잡한 게임 규칙을 붙이지 않는다.
- 정확한 금액·문장 관계·원문 사실은 확인하고 수정한다. 취향·타당한 해석·선택 이유는 차이를 남기고 이해한다. 항상 모두 같은 답에 동의하게 하지 않는다.
- 리듬·박자·동작은 해당 어휘나 표현을 실제로 연습하게 할 때 사용한다. 흥미를 위해 학습 과제를 제거하거나 모든 과목에 같은 놀이를 붙이지 않는다.
- 가리키기·낱말·AAC·계산기·대필로 참여해도 학생의 선택이 다음 활동에 반영되게 한다. 상대가 답이나 결정을 대신하지 않는다.
- 승패·인기·수익 순위를 상호작용의 기본 동기로 쓰지 않는다. 협상에서 거절·보류, 소비에서 구매하지 않기, 투자에서 하지 않기도 유효한 선택이다.
- 사전·사후 진단은 먼저 개별 응답을 확정하고 협력·수정 후 수행을 분리한다. 같은 문항과 지원 조건을 기록해 비교하며 지원이 바뀌면 함께 밝힌다.

## 4. 시간 배분과 활동명 구체화

지정된 차시별 시간과 총시간을 실제로 합산한다. 차시 구성과 휴식 포함 여부는 확인한 조건을 따른다. 준비·자료 읽기·말하기·선택·실행·정리에 필요한 시간을 포함한다. 활동 수나 20분 간격을 고정하지 말고 중심 경험에 충분한 시간을 준다. 사용자가 인원 가정을 허용한 예시안이면 가정한 인원과 진행 방식을 명시한다.

활동명은 **활동 형태 + 실제 행동·대상**으로 쓴다. 단순히 길게 늘리거나 흥미로운 별명만 붙이지 않는다.
- '통장과 카드 준비하기' → '모의 은행 창구 — 통장·체크카드 신청하고 수령하기'
- '예산 조정' → '추가 교통비 2만 원 해결 — 미사용 예산 다시 배분하기'
- '친구와 확인' → '교실 가게 운영 — 주문받고 물건·거스름돈 건네기'

활동명에 있는 소품·숫자·방식은 실제 진행 내용과 일치시킨다. 없는 앱이나 체험을 이름에만 추가하지 않는다.

## 5. 보고 또는 반영

보고·승인 모드라면 아직 외부 페이지를 수정하지 않는다. 현재 문제, 바꿀 기준, 차시별 중심 활동과 원자료 연결을 보여준다. 차이가 잘 드러나지 않으면 대표 차시의 시간별 흐름 하나를 추가한다. 구체적인 결과를 보여준 뒤 한 번 승인받는다.

실행 권한이 있으면 대상 전체를 반영한다. 간결형과 상세형 모두 지도안을 표로 작성한다. 기본 열은 **시간 | 활동명 | 진행 방법 | 자료**이다. 여러 교시면 교시별로 표를 나누고 긴 셀은 문장 단위로 줄을 바꾼다.

자료명·교재 쪽수·슬라이드 번호·링크·준비물 목록은 해당 행의 **자료 열**에 적는다. 진행 방법 본문에 자료 목록이나 출처를 섞어 쓰지 않는다. 진행 방법에는 실제 행동·순서·지원 방법을 쓰며, '카드를 배열한다'처럼 행동을 이해하는 데 필요한 대상 표현은 유지한다. 자료 열에는 원자료와 교사 보충 자료를 구분하고, 준비 전·미확인 자료는 상태를 표시한다. 자료를 별도 열로 옮겨도 원래 과제·금액·조건·자료 연결이 누락되지 않게 한다.

세부 결과물 기본 형식:

```markdown
## [차시] — [중심 활동명]
대상·조건: 확인된 정보와 임시 가정
수업 시간: 지정된 총시간과 차시 구성, 쉬는 시간 포함 여부
학습 목표: 원자료에서 확인했거나 설계를 위해 도출했음을 구분
핵심 활동: 무엇을 경험·연습하고 어떤 수행이나 결과로 확인하는지. 상호작용 활동은 선택·반응의 영향도 설명
### [교시] — [배정 시간]

| 시간 | 활동명 | 진행 방법 | 자료 |
|---|---|---|---|
| 시작–종료분 | 실제 행동이 드러나는 활동명 | 준비·선택·수행·확인 순서와 필요한 지원 | 원자료명·쪽/문항, 보충 자료·준비 상태 |
### 활동지 반영 범위
공통·선택·이월·보충·미확인 구분
```

기존 성취기준은 관련 부분에 보존하되 검증하지 않은 문구를 공식 확인본이라고 주장하지 않는다. 불필요한 평가표·교사 대본·역할 목록·예상 반응·준비물 패키지를 자동으로 늘리지 않는다.

상세 지도안을 요청하면 기본 표에 단계·목표 확인 방법 등을 필요한 만큼 추가하고 진행 방법을 교수학습 과정으로 확장한다. 자료는 항상 독립된 열로 유지하고 지원 방법은 진행 방법 또는 별도 지원 열에 쓴다. 교사 발문·학생 역할·예상 반응은 요청한 경우에만 확장하고 실제 관찰 결과처럼 쓰지 않는다. 간결형에서도 목표, 실행 순서, 시간, 활동지 연결을 빠뜨리지 않는다. 계획된 수행 범위를 실제 학생의 성취나 완료로 보고하지 않는다.

최종 점검: 부분별 수업 방식에 활동지의 내용·과제 성격에 근거한 이유가 있는가, 학생의 선행학습·숙달 여부를 추정하지 않았는가, 필요한 설명·시범·개별 문제풀이 시간을 확보했는가, 원문을 풀어 나열한 수준을 넘어 실행할 활동을 구안했는가, 짝 대화나 동일한 진행 구조에 편중되지 않았는가, 원자료의 핵심 과제가 연결되어 있는가, 목표와 활동이 일치하는가, 학생의 참여 방식이 실행 가능한가, 준비·전환 시간을 포함했는가, 제목과 실제 내용이 일치하는가, 원문과 보충안·미확인이 구분되는가?

### 완료 후 차시별 핵심내용 보고

전체 작성·수정과 확인을 마친 뒤 최종 답변에서 **작업한 모든 차시의 핵심내용**을 보고한다. '몇 개 수정 완료'나 대표 사례만으로 끝내지 않는다. 기본 보고 표는 **과목·날짜/차시 | 핵심 학습내용 | 중심 활동·진행 흐름**이다. 날짜가 없으면 차시만 쓰고 한 수업 안의 1·2교시는 같은 행에서 흐름을 연결한다. 각 행은 무엇을 배우며 무엇을 하는지 1–2문장으로 구체화하고, 수정 작업이면 실제 바뀐 부분을 드러낸다. 형식만 바꾼 작업은 내용 개선으로 보고하지 않는다. 수업 방식을 바꿨다면 중심 활동·진행 흐름 열에 선택한 방식과 핵심 이유도 짧게 적는다.

시간·원자료 보존·자료 확인 한계는 표 아래에 짧게 덧붙인다. 이월·보충·미반영·실패가 있으면 해당 차시에 표시하고 실제 완료한 범위와 구분한다. 외부 편집을 실제로 수행한 경우에만 반영 완료와 결과 링크를 보고한다.

# 선택형 노션 연동

핵심 활동지 분석·수업 설계에는 노션이 필요하지 않다. 사용자가 노션 자료 읽기나 수업안 반영을 요청할 때만 이 지침을 적용한다.

## 접근과 자료 확인

- 현재 제공되는 노션 연결 도구와 권한을 확인한다. 고정된 도구명·API 키·개인 페이지 ID를 요구하거나 저장하지 않는다.
- 연결이 없으면 읽을 자료를 파일이나 텍스트로 제공받아 수업안을 작성한다. 작성한 안을 붙여 넣을 수 있게 제공하고 자동 반영은 미실행으로 표시한다.
- 읽기 권한을 쓰기 권한으로 해석하지 않는다. 보고 후 승인 요청이면 구체적인 개선안을 먼저 제시한다. 이미 승인된 범위는 재승인 없이 수행한다.
- 현재 데이터베이스 스키마, 대상 보기의 행과 페이지를 읽는다. 날짜·과목·완료 여부와 수정 영역을 확인한다.
- 기존 수업안과 원문·OCR·이미지·첨부의 경계를 구분한다. 원자료에 접근하지 못했다면 기존 설명만 확인한 것으로 표시한다.

## 반영과 확인

- 현재 도구의 Markdown 규격을 확인하고 정확한 대상 문자열로 필요한 수업안 영역만 편집한다. 활동명 수정이면 해당 제목만 수정한다.
- 하단 원문·이미지·첨부·하위 페이지와 날짜·수업명 속성·완료 상태는 요청 범위가 아니면 유지한다. 원자료를 이동할 대신 연결하고, 차시간 과제 이월은 양쪽 계획에 명시한다.
- 기존 노션 페이지는 가능한 경우 네이티브 페이지 참조로 연결한다. 도구 이름·페이지 ID를 스킬에 고정하지 않는다.
- 지도안은 시간·활동명·진행 방법·자료의 독립된 열을 가진 네이티브 표로 작성한다. 자료명·쪽수·링크는 해당 행의 자료 열에 넣고 진행 방법 본문과 분리한다. 표 형식만 변경할 때는 활동 내용·시간·자료 연결을 보존한다.
- 여러 변경 후 재조회하여 제목·시간·참조·내용과 원자료 보존을 확인한다. 변하는 서명 URL은 내용 손상으로 오판하지 않는다.
- 오류 시 원인을 확인한 뒤 범위를 좁혀 재시도한다. 반복 실패나 접근 거절이면 미반영 범위를 정확히 보고하고 성공했다고 말하지 않는다.

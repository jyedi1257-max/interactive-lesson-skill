# 목표별 활동 구안과 참여 구성 예

예시는 선택지를 넓히기 위한 것이다. 원자료에 없는 동물·문장·금액을 자동으로 이식하지 말고 해당 자료에 맞추어 설계한다.

| 원래 과제 | 흔한 형식적 상호작용 | 목표를 살리는 진행 | 실제 반응의 결과 |
|---|---|---|---|
| 외모·생활 정보 선택 | 각자 고르고 짝에게 읽기 | 청중이 알고 싶은 범주를 주문하고 설명을 들어 소개판 구성 | 정보가 빠지면 추가 요청, 설명 보충 후 소개판 완성 |
| 접속사 빈칸 | 답 카드 동시에 들기만 반복 | 원래 앞뒤 문장을 나누어 듣고 관계를 판단한 뒤 전체를 공개 | 뒷내용에 따라 연결어가 달라짐 |
| 주제·관련 없는 문장 | 서로 답 채점하기 | 원문을 편집해 핵심 내용을 소개하고 다른 모둠이 주제 선택 | 엇갈린 주제 선택으로 전달 내용의 범위 확인 |
| 표정·마음의 소리 | 감정 이름 맞히기 | 같은 그림에 두 속마음을 더빙하고 각 해석의 그림 근거 찾기 | 서로 다른 해석을 유지하며 이유 이해 |
| 청중·몸 표현 | 좋은 발표 스티커 주기 | 같은 대사를 한 표현 요소만 바꾸어 전달하고 청중의 실제 해석 비교 | 표현 의도와 받은 느낌에 따라 연출 선택 |
| 설득의 네 단계 | 대본 읽고 질문 한 개 받기 | 상대가 걱정되는 점을 선택하고 조건을 협의 | 수락·보류·다른 조건에 맞추어 다음 말 변경 |
| 상품·능력 소개 | 상품 칭찬하고 인기투표 | 청중이 필요를 선택하고 발표자가 같은 상품의 강조점 조정 | 청중의 필요에 맞는 설명, 능력 소개 후 짧은 체험 |
| 물건값·거스름돈 | 둘이 같은 계산 풀기 | 원문 상품 중 실제 주문을 선택해 물건·돈·거스름돈 주고받기 | 주문이 바뀌면 제공할 물건과 계산도 바뀜 |
| 채용공고 읽기 | 공고 항목 함께 밑줄 | 개인이 중요한 조건을 골라 문의하고 조건표 작성 | 같은 공고에서도 지원·추가 확인·보류가 달라짐 |
| 저축 계획 | 친구의 곱셈 검산만 하기 | 본인이 목표와 가능한 월 금액을 정하고 상대가 기간 대안 제시 | 목표·기간·금액 중 무엇을 조정할지 본인이 결정 |
| 은행 이용 | 고정 대본대로 번호표 놀이 | 입금·출금 등 업무를 선택해 요청하고 결과표 확인 | 업무와 금액에 따라 절차·잔액 변화 |
| 합리적 소비 | 가장 싼 상품 맞히기 | 각자의 만족 기준을 제시하고 예산 안의 공동 외출 협의 | 서로 양보 가능한 부분과 개인 선택이 달라짐 |
| 가계부·결산 | 주어진 영수증을 베끼기 | 실제 모의 선택에 따라 영수증을 받아 기록, 추가 지출 조건 적용 | 이미 쓴 돈을 되돌리지 않고 남은 예산 재배분 |
| 투자 개념 | 무작위 수익 게임 | 모든 학생에게 같은 복수 결과를 주고 돈의 목적·시점에 적용 | 손실 상황에서 목적 달성 가능성을 보고 판단 |

## 짝 활동 밖의 구안 후보

아래는 선택 가능한 예시다. 원자료의 과제와 목표에 맞을 때만 적용하며 정해진 순서나 필수 구성으로 쓰지 않는다. 같은 활동도 인원과 지원에 따라 구성을 조정한다.

| 원래 과제 | 활동 방식과 참여 구성 | 실행할 활동 | 학습을 확인할 수행 |
|---|---|---|---|
| 목표 어휘의 음절·발음 연습 | 리듬 연습 / 전체 동시 → 필요한 개별 연습 | 단어 박자 맞추기 — 원자료 단어를 음절별로 짚고 박수·말·카드로 표현, 어려운 부분만 다시 연습 | 각 학생이 목표 단어의 음절과 발음을 수행. 빠르기·승패 경쟁은 불필요 |
| 순서에 따른 정보 전달 | 수행 실험 / 전체 안내·개별 조작 | 설명 따라 완성하기 — 원문 절차를 한 학생이 안내하고 모두 각자 자료를 배치, 결과 차이로 빠진 설명을 찾아 재실행 | 절차 표현과 실제 수행 결과를 대조 |
| 같은 말의 표현 차이 | 표현 실험 / 전체 비교·개별 선택 | 같은 대사 다른 느낌 — 원문 대사의 목소리나 표정 한 요소를 바꿔 시연, 각자 받은 느낌을 표시하고 근거 비교 | 표현 요소에 따라 전달되는 느낌이 달라짐을 설명·선택 |
| 주제·불필요한 문장 찾기 | 자료 편집 / 소집단 제작 → 전체 검토 | 한 장 안내문 편집실 — 원문 문장 조각을 골라 배열해 안내문 제작, 독자가 파악한 주제와 제작 의도 비교 | 선택·제외한 문장이 주제와 연결되는 이유 |
| 물건값·거스름돈 | 모의 운영 / 소집단 기능 연결 | 교실 가게 운영 — 원문 상품으로 주문·물건 준비·계산·영수증을 연결하고 교대 | 주문에 맞는 물건과 금액, 각자의 계산 기록. 단순 역할 명찰 놀이로 끝내지 않음 |
| 저축 목표와 기간 계산 | 계획 조작 / 개별 탐색 → 필요한 상담 | 내 저축 일정판 만들기 — 원문 조건 안에서 목표·월 금액을 배치하고 가능한 기간 비교 | 금액과 기간의 관계를 확인하고 본인의 계획 선택 |

## 반복된 진행 구조를 발견했을 때

1. 먼저 이미 잘 구안된 활동을 남긴다. 모든 차시를 일괄 교체하지 않는다.
2. 편중된 활동의 원래 학습 목표를 다시 확인하고, 대화 외의 학습 행동 후보를 검토한다.
3. 예: 세 활동이 모두 '작성→짝 발표→확인'이면, 발음은 리듬 연습, 표현은 같은 대사 비교 실험, 거래는 교실 가게 운영이 적합한지 각각 판단한다. 원자료에 그 목표가 없는 경우 이 예시를 이식하지 않는다.
4. 수정 전후에 실제 학생 행동·진행 방식이 달라졌는지 확인한다. 참여 인원이나 제목만 달라졌다면 다시 검토한다.

## 활동 설계의 마무리 확인

- 학습 목표에 맞는 구체적인 학습 행동과 진행 흐름이 있는가?
- 짝 발표·확인 절차가 반복되지 않는가? 참여 인원만 바꾸어 다양성으로 포장하지 않았는가?
- 상호작용 활동이라면 설명을 들은 사람이 실제로 하는 행동이 있는가?
- 정보차가 필요한 활동이라면 정보를 모두 미리 공유하여 목적이 사라지지는 않는가? 같은 자료를 함께 비교하는 활동에는 정보차를 강제하지 않았는가?
- 대화가 필요한 목표인가, 조용한 개별 연습이 더 적절한 부분인가?
- 금액·사실 오류와 타당한 선택 차이를 구분했는가?
- 읽기가 어려운 학생도 자료를 보고 선택할 수 있는가?
- 조건 카드·모의 영수증 등 보충 장치를 원문 과제로 오인시키지 않는가?
- 활동 이름에서 대상과 행동이 보이고, 본문과 일치하는가?
- 같은 과제를 다시 수행하는 것과 다른 과제로 일반화하는 것을 구분했는가?

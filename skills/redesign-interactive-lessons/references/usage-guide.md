# 사용 안내와 배포 구성

## 이 스킬의 범위

활동지를 분석해 학습할 내용을 파악하고, 실제로 진행할 수 있는 수업활동과 지도안으로 개선한다. 특정 앱·계정·교재를 필요로 하지 않는다. 활동 방식을 먼저 구안한 뒤 개별·짝·소집단·전체 중 적절한 참여 구성을 선택한다. 짝 대화로 모든 과제를 처리하거나 구성의 다양성을 위해 불필요하게 자리를 바꾸지 않는다. 원자료를 읽는 기능과 스킬 설치 방식은 이용 환경에 따라 다르며, 모든 AI 제품에서의 작동을 보장하지 않는다.

## 세 부분의 구성

| 부분 | 내용 | 필수 여부 |
|---|---|---|
| 핵심 스킬 | 활동지 분석 → 수업활동 재구성 → 지도안 작성, 목표별 활동 변환 예 | 필수 |
| 노션 연동 지침 | 지정한 자료 읽기, 승인 범위 편집, 원자료 보존 및 재확인 | 노션 요청 시만 |
| 사용 안내 | 입력 방법, 조정 가능한 조건, 결과물 예시와 한계 | 시작할 때 참고 |

## 먼저 확인할 기본정보

활동지와 함께 아래 기본정보를 제공한다. 빠진 정보는 스킬이 짧게 확인하며 이미 알려준 내용은 다시 묻지 않는다. 이름이나 진단명 대신 설계에 필요한 읽기·표현 방식을 설명한다.

- 수업 시간: 총 __분 / __차시 / 휴식 포함 여부 __
- 대상: __학교 __학년 또는 __세 / 학급·집단 유형 __
- 인원: __명
- 참여 수준·지원: 읽기·이해·표현 방식 __ / 필요한 지원 __
- 과목·주제와 활동지 범위: __
- 선택 사항: 강조할 목표, 준비물·공간 제한, 간결형/상세형 희망

활동지 분석은 먼저 진행할 수 있으나 핵심 조건을 임의로 채워 완성 지도안을 만들지 않는다. “조건은 정해서 예시로 만들어줘”처럼 사용자가 가정을 허용한 경우에는 가정한 조건을 표시한다.

- 시간: 먼저 확인하며 100분을 자동 적용하지 않음.
- 결과물: 기본은 시간·활동명·진행 방법·자료의 4열 표. 자료명·쪽수·링크·준비물은 자료 열에 분리하며 요청하면 상세형으로 확장.
- 완료 보고: 작업한 모든 차시의 핵심 학습내용과 중심 활동·진행 흐름을 최종 답변의 요약 표로 보고.
- 자료: 원문 확인 범위 안에서 분석. 없는 문항이나 그림을 추측하지 않음.
- 연동: 노션 없이도 핵심 작업 가능. 외부 편집은 요청·승인 범위에 따름.

## 복사해 쓰는 요청문

> 첨부 활동지를 분석해서 수업활동과 지도안으로 개선해줘. 총 45분, 학생 6명이고 2명은 그림카드로 응답해. 원래 과제와 학습 목표를 살리고 구체적인 활동명, 시간, 진행 방법, 활동지 연결을 보여줘.

> 먼저 원래 활동과 기존 수업안을 대조해줘. 누락·축소·선택·이월·미확인 부분을 구분하고 개선안을 제안해줘.

> 위 수업활동을 상세 지도안으로 바꿔줘. 단계, 시간, 교수학습 과정, 필요한 자료와 지원, 목표 확인 방법을 포함해줘. 교사 발문과 예상 반응은 생략해줘.

> 승인한 개선안을 노션의 지정한 차시 수업안에 반영해줘. 원문·이미지·첨부자료와 완료 상태는 유지해줘.

## 개선 예시

설명용 창작 예시이며 교재 원문이나 실제 수업 효과 검증 결과가 아니다.

| 원래 과제 | 개선 활동 | 지도안에 구체화할 내용 |
|---|---|---|
| 물건값과 거스름돈 계산 | 교실 가게 운영 — 주문받고 물건·거스름돈 건네기 | 원자료 상품, 구매 선택, 계산과 확인, 역할 교대, 개인별 계산 기록 |
| 정보 전달 순서 익히기 | 설명 따라 완성하기 — 친구의 안내로 준비물 배치하기 | 원자료 순서 표현, 안내와 실행, 누락된 정보 요청, 설명 보완 |
| 그림 속 마음 표현 | 한 장면 두 속마음 — 서로 다른 해석 더빙하기 | 그림 근거 확인, 두 해석 표현, 비교하며 차이 이해 |

## 배포 안내

스킬 폴더의 지침·참고자료·메타데이터·아이콘을 함께 유지한다. 제품별 설정 파일은 공통 지침과 구분한다. GitHub 소개문에는 이 안내의 입력 방식·예시·조정 조건을 안내한다. 학생 정보·개인 페이지 주소·API 키·공유 권한 없는 교재를 포함하지 않는다. 이용 허락 범위와 라이선스는 제작자가 결정하며 이 지침이 임의로 정하지 않는다.
